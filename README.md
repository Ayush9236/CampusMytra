# CampusMytra

A campus social platform and gaming application built with Flutter.

## Features
- **Campus Buzz**: Stay updated with college feeds and announcements.
- **Playground**: Multiplayer UNO and real-time DSA Combat.
- **Fitness Buddy**: Personalized AI-driven workout and diet plans.
- **Chatter**: 1-on-1 and group messaging for students.

## Getting Started

1. Clone this repository.
2. Run `flutter pub get` to install dependencies.
3. Run `flutter run` to start the app.
